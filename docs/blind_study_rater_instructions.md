# Rater Instructions: Room Arrangement Study

### Important Notice

> **Do each study only once; do not complete both.**

---

### Evaluation Question

> **Which room arrangement looks more sensible?**

---

### Procedure

1. Extract the downloaded zip bundle (`study_1_rater_bundle.zip` or `study_2_rater_bundle.zip`).
2. Open `index.html` in any modern web browser (Edge, Chrome, Safari, Firefox). No internet connection or installation required.
3. Enter your Rater ID or Name and click **Begin Evaluation**.
4. For each of the 32 rooms, evaluate the two 3D arrangements (Arrangement A and Arrangement B) and choose:
   - **Arrangement A** (Key: `1`)
   - **Arrangement B** (Key: `2`)
   - **Tie / Similar** (Key: `3`)
5. You can navigate back and forth with `Previous` (`←`) and `Next` (`→`).
6. When finished, click **Export Ratings (JSON)** to download your evaluation file.
7. Return the exported JSON file to the study coordinator.
